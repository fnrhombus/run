# Writing prose

Delegate all substantive prose authoring/editing — docs, READMEs, design notes,
PR descriptions, long-form explanations — to the `prose-writer` Sonnet subagent
(`.claude/agents/prose-writer.md`). It writes more readable prose than the
default model. Draft/structure content first; hand it to `prose-writer` for the
writing pass once the content is stable. (Does not apply to code, code comments,
commit subject lines, or short chat replies.)
